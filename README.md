# QR-гид · Српски историјски музеј

Мобильный веб-гид: посетитель сканирует QR у экспоната — открываются фото, текст и аудиогид.
4 языка (sr / en / ru / zh), крупный шрифт (100–200 %), высокая контрастность, кириллица/латиница для сербского,
аудиоплеер, карта музея, офлайн-режим (PWA). Без фреймворков и сборки — это папка `public/`.

## Запуск
```bash
npm install
npm start          # http://localhost:8080  (+ адрес для телефона в той же Wi-Fi сети)
```

## Публикация
Загрузите содержимое `public/` на любой статический хостинг (Cloudflare Pages, Netlify, GitHub Pages, сервер музея).
Нужен **HTTPS** (для офлайн-режима и аудио в фоне). Service Worker (`sw.js`, версия в `VERSION` — менять при каждом выпуске) кладёт в кэш оболочку, шрифты и все фото; аудио кэшируется при первом прослушивании или кнопкой «Аудио без интернета» в настройках. Адреса вида `https://хост/#/o/regalia` работают без настройки сервера.

## Структура
Старт (выбор экспозиции) → экспозиция (залы и список экспонатов) → экспонат. Экспозиции описаны в `exhibitions` (`content.js`);
`active: false` — карточка-«заглушка» («Гид скоро появится» / «Временно закрыто»). Чтобы добавить новую экспозицию,
заведите для неё экспонаты с номерами 100+, и расширьте `viewExhibition` (сейчас гид есть только для «В ожидании постоянной экспозиции»).

## Первый запуск и язык
При первом открытии стартового экрана показывается онбординг из трёх шагов (язык → как найти табличку и сканировать → аудио и настройки); если человек пришёл сразу по QR на экспонат, онбординг пропускается. Повторно: «Аа» → «Как пользоваться».
Язык переключается сегментным переключателем на старте и кнопкой «РУ/EN/СР/中» в шапке (лист с четырьмя вариантами). Кнопка с эмблемой в шапке возвращает на главный экран.
Тексты на сербском — из присланного `Tekst za deplijan (1).docx` (исправлены две опечатки: «Алаксандра», «Посебну место»).

## Стиль
«Златовез на тёмном бархате»: винно-чёрный фон, золотая нить (тонкие линии, печати-номера), пергаментный текст, сводчатая арка для фото,
шрифт заголовков Cormorant. Современное: бенто-плитки залов, плавающая «стеклянная» панель, плавные переходы между экранами (View Transitions), мягкое появление карточек. Архаичное: красная «заставица» (буквица) в начале текста, как в рукописных книгах, золотая рамка-«кивот» вокруг фото, арка-ниша, печати-номера, лёгкая «пергаментная» зернистость. Красный — только для главного действия (сканер, плеер). Токены — в начале `public/css/app.css`.

## Тема
Настройки (кнопка «Аа»): «Системная» (по умолчанию, следует настройке телефона и меняется на лету) / «Светлая» / «Тёмная».
Светлая — «пергамент»: те же золото, киноварь и шрифты. Палитры — переменные в начале `app.css` (`:root` — тёмная, `[data-scheme="light"]` — светлая);
поверх фотографий и камеры цвета всегда тёмные. «Высокий контраст» перекрывает обе темы.

## Таблички и QR-коды
У каждого экспоната — номер (`n` в `content.js`: 10/20/30 — залы, 11–14 левое крыло, 21–25 правое).
QR ведёт на `…/#/e/<номер>`. Печатная табличка: номер, QR и подпись «Скенирајте · Scan · Сканируйте · 扫码» на 4 языках.
```bash
BASE_URL=https://ваш-адрес/ npm run qr     # PowerShell: $env:BASE_URL="https://..."; npm run qr
```
Создаст `qr/<номер>.svg` и `qr/print.html` (A4 → «Печать → PDF»). `qr/start.svg` — для входа в музей.
В самом гиде: кнопка «Сканировать табличку» (камера, jsQR / BarcodeDetector) и «Номер» (ввод вручную, если камера недоступна).

## Добавить / изменить экспонат — `public/js/content.js`
Добавьте объект в `items` (`id` попадает в QR; `hall`: left | right | medieval; `x,y` — позиция на плане;
`images` — файлы в `public/img/`; тексты на 4 языках; сербский — кириллицей, латиница строится автоматически).
Затем `npm run qr`.

## Аудио
Сейчас есть русская озвучка всех 13 станций (`public/audio/*.ru.mp3`, ~4,4 МБ): введение в выставку (`exhibition-waiting`, на странице экспозиции),
три зала и 9 экспонатов. Запись длиной 10:55 была разрезана по паузам перед названиями разделов (расшифровка локальной моделью Whisper,
проверено по началу и концу каждого фрагмента), сжата до моно 56 кбит/с. Английская озвучка (`*.en.mp3`, 13 файлов) нарезана тем же способом из второй записи (11:33) по паузам, найденным по пословным таймкодам. Для sr и zh файлов пока нет — работает голос устройства.
Положите записи `public/audio/<id>.<lang>.mp3` (например `regalia.ru.mp3`) — плеер подхватит их сам
(перемотка, ±10 с, скорость, управление с экрана блокировки).
Если файла нет — текст озвучивает голос устройства (Web Speech API), с подсветкой читаемого предложения.
Качество и наличие голосов зависят от телефона (для сербского и китайского могут отсутствовать) —
для музея лучше записать дикторов или сгенерировать озвучку и положить mp3.

## Карта
Сейчас — схематичный план (`map` в `content.js`, зоны рисуются в `viewMap`, `app.js`).
Чтобы подключить настоящий план: положите SVG/PNG в `public/img/` (пропорции 400×300 или измените `map.viewBox`),
укажите `map.image: 'img/plan.svg'` и поправьте `x,y` у экспонатов.
